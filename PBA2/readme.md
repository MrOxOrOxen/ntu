## Run order

1. Run task2.m.
2. Open task3_simulink.slx and run task3.m before simulation.
3. Open task4_simulink.slx and run task4.m before simulation.
4. Set k as 0.1, 0.2 and 0.4 and run Simulink simulation. Rename 'out' in the workspace as 'out1', 'out2' and 'out4', and then run task4_k_comparison.m.
